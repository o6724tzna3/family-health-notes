# 韭菜根的药用价值有哪些

> 更新时间：2026-09-15 (UTC+8)

**1韭菜肉饺子馅的做法**

　　对韭菜肉饺子馅的做法都有什么呢，也是很多人不太了解到，在制作这样美食的时候，在对它制作上，都是要进行很好的认识，使得选择的时候，也知道该怎么做最佳。

　　韭菜肉饺子馅的做法：

　　韭菜肉饺子馅的原料：猪肉、韭菜

　　韭菜肉饺子馅的配料：姜

　　韭菜肉饺子馅的调料：黄酒、五香粉、椒盐、盐、鸡精适量

　　韭菜肉饺子馅的做法：

　　1、猪肉最好是夹心猪肉，剁肉馅、切姜末，姜末少许要切得尽量细;

　　2、切韭菜;

　　3、荤素比例1：1，倒入韭菜、猪肉馅、调料，用劲搅匀;

　　4、饺子怎么包请点击：饺子的包法。

　　韭菜的营养价值：

　　1、补肾温阳：韭菜性温，味辛，具有补肾起阳作用，故可用于治疗阳痿、遗精、早泄等病症;

　　2、益肝健胃：韭菜含有挥发性精油及硫化物等特殊成分，散发出一种独特的辛香气味，有助于疏调肝气，增进食欲，增强消化功能;

　　3、行气理血：韭菜的辛辣气味有散瘀活血，行气导滞作用，适用于跌打损伤、反胃、肠炎、吐血、胸痛等症;

　　4、润肠通便：韭菜含有大量维生素和粗纤维，能增进胃肠蠕动，治疗便秘，预防肠癌。

　　美食禁忌：

　　韭菜：

　　韭菜+牛奶：牛奶中含钙。钙是构成骨骼和牙齿的主要成份。牛奶与含草酸多的韭菜混合食用,就会影响钙的吸收。

　　韭菜+牛肉： 同食容易中毒，可以用人乳和鼓汁解毒。

　　韭菜+蜂蜜： 同食会阻碍血液循环

　　猪肉：猪肉不宜与乌梅、甘草、鲫鱼、虾、鸽肉、田螺、杏仁、驴肉、羊肝、香菜、甲鱼、菱角、荞麦、鹌鹑肉、牛肉同食。食用猪肉后不宜大量饮茶。

**2韭菜根的药用价值有哪些**

　　1.韭菜根的壮阳作用

　　韭菜根具很好的壮阳作用，它可以入药，也可以直接泡水饮用。韭菜根对男性的阳痿、早泄以及女性的月经不调等症都很好的调理作用。如果经常用韭菜根泡水喝，会起到温补肾阳的作用。

　　2.韭菜根的杀菌消炎作用

　　韭菜根具良好的消炎杀菌作用，特别是对人肠道中的各种细菌很好的抑制作用，人们经常食用韭菜根，会大大减少痢疾和伤寒等肠道疾病的发生。

　　3. 韭菜根的通便作用

　　韭菜根中含大量的膳食纤维，它进入人体的肠道后，会加增肠道的蠕动，会减轻人们便秘带来的不适，另外韭菜根对防止人体出现肠癌也着重要的作用。

　　4. 韭菜根具止血止痛的功效

　　韭菜根在炒制以后，加工成粉状，是很出色的外伤药，它不但可以止血，促进人们伤口的愈合，更能起到消肿止痛的作用。另外韭菜根对于跌打损伤也止痛的作用，可以用韭菜根煮水，浸泡患处，从而达到止痛的目的。

**3春季吃韭菜的好处与禁忌**

　　增进食欲

　　韭菜中含有植物性芳香挥发油，具有增进食欲的作用，老人、孩子、孕妇等适当吃些春韭，有益于增进健康。

　　益肝健胃

　　韭菜含有挥发性精油及硫化物等特殊成分，散发出一种独特的辛香气味，有助于疏调肝气，增进食欲，增强消化功能;

　　散瘀活血

　　韭菜有散瘀、活血、解毒的功效，有益于人体降低血脂，防治冠心病、贫血、动脉硬化。

　　润肠通便

　　韭菜含有大量维生素和粗纤维，能增进胃肠蠕动，治疗便秘，预防肠癌。

　　杀菌消炎

　　韭菜所含的硫化合物有一定杀菌消炎的作用，可抑制绿脓杆菌、痢疾、伤寒、大肠杆菌和金黄色葡萄菌。

　　护肤明目

　　韭菜富含维生素A，多吃不仅能美容护肤、明目和润肺，还能降低患伤风感冒、寒喘等疾病的几率。

　　降血脂

　　韭菜具有散瘀、解毒的功效，不但有效降低血脂，防治冠心病、贫血与动脉硬化，所以不妨适当多吃韭菜。

　　补气壮阳

　　古人称韭菜为“壮阳草”，可防治阳萎、多尿、腰痛、腿软等肾气虚症。

　　美容护肤

　　韭菜含有丰富维生素A，吃韭菜可以不但可以美容护肤，明目、还可以有效降低患伤风感冒、寒喘等疾病的机率。

　　吃韭菜禁忌：

　　(1)阴虚火盛者不宜食用韭菜辛温助阳，能燥动相火，耗竭真阴，动物实验表明可使被实验的动物出现狂躁、痉挛乃至死亡，故《本草求真》说：“火盛阴虚，用之最忌。”

　　(2)夏日不应多食夏日韭菜多老化，纤维多而粗糙，不易被吸收，夏季胃肠功能降低，多食会引起腹胀不适或腹泻。

　　(3)食用时不应加热时间过久韭菜中含有丰富的维生素B，加热能使这补成分破坏，加热时间越久，破坏越多。故不应长时间加热后食用。

　　(4)不应生食韭菜既不可加热时间过久食用也不可生食，因韭菜纤维素较多，又难以消化，又不象葱蒜可剥皮后生食，食用部分离地面较近，常污染微生物、寄生虫卵，且分株较多，不容易淘洗干净，容易感染疾病，故不宜生食。

　　(5)不应与蜂蜜同时食用韭菜含有丰富的维生素C，和蜂蜜同时食用，所含的维生素C容易被蜂蜜所含的矿物质铜、铁离子氧化而失去作用。又蜂蜜性滑利通肠，韭菜含有丰富的纤维素能导腹泻，二者同食，能导致泄泻。故《本草品汇精要》说：“不可与蜜同食。”

　　(6)服维生素K时不应食用服维生素K时忌食含维生素C多的食品，本品维生素c含量甚高，同用可降低维生素K的疗效。

　　(7)不宜与白酒同食易引起胃炎、溃疡病发作，易致肝病及出血性疾病。

　　(8)不宜与牛肉同食，易致牙龈炎症。

**4韭菜的做法有哪些**

　　韭菜在我们日常生活中是一种常见的食材，对我们人体也很有益处，而且孕妇适量吃一些韭菜还能有助于通便，很多人都很喜欢吃。那么，很多人都想问，韭菜的做法有哪些呢?事实上，韭菜适用于非常多的烹调方法，而且能够跟韭菜一起搭配的食材也非常之多，所以说，韭菜的做法有很多，而且，它既可以作为一道菜中的主要食材，也可以用来调味。

　　韭菜是老百姓饭桌上比较常见也是比较喜爱的一种蔬菜，做法和搭配也是多种多样的。韭菜最常见的做法就是炒，可以就这么直接炒，也可以加上鸡蛋、一些肉类或者是其他的食材一起炒，很多的食材都可以与韭菜搭配，而且味道都不错。也可以跟其他的食材一起剁碎了作为馅料包在饺子或者是包子里。韭菜也可以直汆熟，加些调味料就可以吃了。也可以在粥里放一些韭菜，增加一些味道。还可以做韭菜盒子、煎饼之类的食物，也是非常美味的。但是需要注意的是，韭菜跟牛肉、蜂蜜、菠菜以及白酒是相克的，不能一起吃，否则可能会对身体造成不良的影响。

**5韭菜可以壮阳吗**

　　我国民间素有“男不离韭，女不离藕”的说法，而且一直都流传着吃韭菜能够壮阳的说法，那么，很多人都想知道，韭菜能壮阳吗?

　　韭菜是葱科葱属的多年生草本植物，丛生，叶细长而扁，开小白花。叶和花嫩时可以食用。对于韭菜来说，最特别的自然是其中的含硫化合物(如二甲基二硫醚，丙烯基二硫醚等)，而韭菜之所以能够散发出来的那种特殊的辛辣香味，就是因为有这些硫化物的存在。虽然韭菜中的这类物质的种类多达20多种，但是直到现在，还没有发现一种能作用于生殖系统。目前比较广泛的说法是因为韭菜含有锌，所以能够壮阳。锌的主要作用在于促进雄性器官的正常发育，并维持精子的活性。但是，其实韭菜的锌含量非常低，每100克韭菜含锌量只有0.43毫克左右。所以说，韭菜是非常有益的一种蔬菜，但是它并没有特别的能够壮阳的效果。

　　虽然韭菜不能壮阳，但是不论男性女性，都可以适当地吃一些韭菜，对身体是很有益处的，而且孕妇多吃的话能够通便，有助于缓解孕期常出现的便秘问题。
